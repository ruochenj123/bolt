FIGURE 1: Baseline N-Way Join Execution (fig:nway-baseline)
================================================================================

Query: SELECT c.c_custkey, c.c_name, c.c_address, o.o_totalprice, 
              l.l_quantity, l.l_extendedprice
       FROM customer c 
       JOIN orders o ON c.c_custkey = o.o_custkey
       JOIN lineitem l ON o.o_orderkey = l.l_orderkey
       ORDER BY c.c_custkey

- HashProbe₁ extracts ALL columns again
- Redundant column extraction at each level!

│   │ c_custkey    │      │  │  Keys: c_custkey + rowRef               │  │  │

│   │ ...          │      │                                               │  │

                                           │
                                           ▼ Hash Table
┌─────────────────────────────────────────────────────────────────────────────┐
│ Pipeline 1: TableScan → HashProbe₀ → [DEFER] → HashBuild₁                   │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│   ┌──────────────┐      ┌─────────────────────────────────────────────────┐│
│   │    orders    │      │     HashProbe₀ (Late-M Output Mode)             ││
│   │  (TableScan) │─────▶│                                                 ││
│   │              │      │  1. Probe hash table                            ││
│   │ o_custkey    │      │  2. For each match:                             ││
│   │ o_orderkey   │      │     - Get buildRowPtr (pointer to container₀)   ││
│   │ o_totalprice │      │     - Encode probeRowId for orders payload      ││
│   └──────────────┘      │     - Store orders payload in ProbePayload₀     ││
│                         │                                                 ││
│                         │  Output (KEYS ONLY):   ProbePayloadContainer₀:  ││
│                         │  ┌─────────────────┐   ┌────────────────────┐   ││
│                         │  │ c_custkey (key) │   │ o_totalprice       │   ││
│                         │  │ o_orderkey (key)│   │ (columnar batches) │   ││
│                         │  │ buildRowPtr───────▶ │                    │   ││
│                         │  │ probeRowId────────▶ │                    │   ││
│                         │  └─────────────────┘   └────────────────────┘   ││
│                         └─────────────────────────────────────────────────┘│
│                                   │                                        │
│                                   ▼                                        │
│   ┌─────────────────────────────────────────────────────────────────────┐  │
│   │              HashBuild₁ (Late-M Input Mode)                          │  │
│   │  ┌─────────────────────────────────────────────────────────────┐    │  │
│   │  │ HybridContainer₁                                            │    │  │
│   │  │  Keys: c_custkey, o_orderkey + rowRef                       │    │  │
│   │  │  upstreamBuildRowPtr → container₀ row                       │    │  │
│   │  │  upstreamProbeRowId → ProbePayload₀ row                     │    │  │
│   │  │  (NO payload columns stored - just references!)             │    │  │
│   │  └─────────────────────────────────────────────────────────────┘    │  │
│   │                                                                     │  │
│   │  columnSourceMap (extended):                                        │  │
│   │  {                                                                  │  │
│   │    c_custkey    → (HYBRID_KEY, container₁, col0)                    │  │
│   │    c_name       → (HYBRID_PAY, container₀, col0)  ◄── still at 0!   │  │
│   │    c_address    → (HYBRID_PAY, container₀, col1)  ◄── still at 0!   │  │
│   │    o_orderkey   → (HYBRID_KEY, container₁, col1)                    │  │
│   │    o_totalprice → (PROBE_PAY, ProbePayload₀, col0)                  │  │
│   │  }                                                                  │  │
│   └─────────────────────────────────────────────────────────────────────┘  │
└─────────────────────────────────────────────────────────────────────────────┘
                                           │
                                           ▼ Hash Table
┌─────────────────────────────────────────────────────────────────────────────┐
│ Pipeline 2: TableScan → HashProbe₁ → [FINAL MATERIALIZE] → Sort → Output   │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│   ┌──────────────┐      ┌─────────────────────────────────────────────────┐│
│   │   lineitem   │      │     HashProbe₁ (Final Materialization Mode)     ││
│   │  (TableScan) │─────▶│                                                 ││
│   │              │      │  1. Probe hash table                            ││
│   │ l_orderkey   │      │  2. For each match, get row from container₁     ││
│   │ l_quantity   │      │  3. Follow upstreamBuildRowPtr → container₀     ││
│   │ l_extendedp. │      │  4. Use columnSourceMap to locate each column:  ││
│   └──────────────┘      │                                                 ││
│                         │     c_custkey    ← container₁.keys[col0]        ││
│                         │     c_name       ← container₀.payload[col0]     ││
│                         │     c_address    ← container₀.payload[col1]     ││
│                         │     o_totalprice ← ProbePayload₀[col0]          ││
│                         │     l_quantity   ← current probe input          ││
│                         │     l_extendedp. ← current probe input          ││
│                         │                                                 ││
│                         │  5. Single-pass extraction from all sources!    ││
│                         └─────────────────────────────────────────────────┘│
│                                   │                                        │
│                                   ▼                                        │
│                         ┌─────────────────┐      ┌──────────────┐          │
│                         │ Output (full)   │─────▶│     Sort     │──▶ Out   │
│                         │ c_custkey       │      │              │          │
│                         │ c_name          │      └──────────────┘          │
│                         │ c_address       │                                │
│                         │ o_totalprice    │                                │
│                         │ l_quantity      │                                │
│                         │ l_extendedprice │                                │
│                         └─────────────────┘                                │
└─────────────────────────────────────────────────────────────────────────────┘

KEY BENEFITS:
- HashProbe₀ outputs only KEYS (c_custkey, o_orderkey), not payload!
- HashBuild₁ stores only REFERENCES, not materialized data!
- Payload columns extracted ONCE at final HashProbe₁
- No redundant column-to-row-to-column conversions!

SAVINGS:
- HashProbe₀: No payload extraction (only keys)
- HashBuild₁: No payload re-storage (only references)
- Total column extractions: N → 1 (where N = number of join levels)
